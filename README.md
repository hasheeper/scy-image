# Scylla Image

NAI 图片生成前端。纯静态、零依赖、零构建，可直接部署到 GitHub Pages，也可用本地 Node 服务运行。

## 两种运行方式

**GitHub Pages（浏览器直连）**

Settings → Pages → Source 选 **Deploy from a branch**，Branch 选 `main` + `/docs`。
（Pages 只支持仓库根目录或 `/docs`，这是站点放在 `docs/` 的原因。）

上游已开放 CORS，浏览器直接请求，无需任何中转服务。Key 保存在你自己的浏览器里。
所有资源引用均为相对路径，因此在 `user.github.io/repo/` 这类子路径下同样可用。

**本地（后端持有 Key）**
```bash
# 在 config/api-key.txt 写入 token，然后
npm start   # → http://127.0.0.1:3215
```
此模式下 Key 只由本机后端读取，不进入浏览器。前端会自动探测并切换。
需要 Node 18+，无需 `npm install`。

## Key 的存放与加密

首次打开会要求填写 Key，两种保存方式：

- **口令加密保存** — PBKDF2-SHA256（21 万次迭代）派生密钥，AES-GCM 加密后存入
  localStorage。之后每次打开输入口令解锁；解密后的 Key 只存在内存变量中。
- **仅本标签页** — 明文存 sessionStorage，关闭标签即消失，不落盘、无需口令。

关于加密边界，说清楚比说好听重要：

| 能防 | 不能防 |
| --- | --- |
| 他人翻看本机 localStorage | 页面遭 XSS 或恶意扩展在解锁状态下读取内存明文 |
| 浏览器配置同步外泄 | 解锁后有人 hook `fetch` |
| Key 被误提交进 git | — |

静态站点最终必须以明文请求头把 Key 发给上游，这是原理限制，客户端加密无法消除。
如果你不信任部署环境，就用「仅本标签页」模式，或改用本地后端模式。

顶栏「锁定」按钮的行为取决于保存方式：

- 口令加密模式 — 丢弃内存中的 Key，下次打开需重新输入口令。
- 仅本标签页模式 — 没有口令可验证，因此会直接清除 Key，需重新填写（会先确认）。
- 本地后端模式 — 浏览器从不持有 Key，按钮隐藏。

## 默认行为

- **不缓存到服务端**（`cache: false`）— 每次都真实生成。
- **历史仅存于本次会话** — 保留最近 24 张图及其完整参数，可点击缩略图回看、
  一键「复用参数」、单张删除或清空。**刷新后清空**（图片只在内存，不落盘）。
- **不压缩**（`optimize: false`）— 返回全质量 PNG。开启后上游会转为 JPEG（有损）。
- **不改写 Prompt**（`transform_prompt: false`）— 不经过任何 LLM 处理。

## 只支持 NAI

模型列表从 `GET /v1/image/models` 动态获取并过滤为 `provider: novelai`。
上游同时公布了 Imagen 模型，但实测 `aspect_ratio` / `ratio` / `width+height` /
不带尺寸四种参数组合全部返回失败占位图，因此不予提供。

## 两个实测结论

**上游用 HTTP 200 表示失败。** 参数非法时（例如分辨率超限）返回的是一张
512×256 的 PNG，像素内容是「Generation Failed」字样。前端已按尺寸特征拦截，
并在提交前做分辨率守卫（NAI 上限约 1.05M 像素，即 1024×1024 或 832×1216）。

**seed 不保证可复现。** 两次 `seed` 相同、`cache: false` 的请求返回了不同的
图像数据。因此 seed 由前端生成并记录，仅用于溯源，不承诺重现同一张图。

## 移动端

单列布局，顺序为 图片 → 历史 → 控制项：

- 历史在图片下方变为横向缩略图条，可横滑
- 生成按钮吸底，44px 触控高度，避让 iOS home indicator（`env(safe-area-inset-bottom)`）
- 用 `dvh` 而非 `vh`，避免地址栏收起时的高度跳动
- 触屏下不显示悬停提示，改用 `aria-label`；删除按钮与图片元信息常驻显示
- 拖拽分栏在触屏隐藏（无指针可拖）

| 键 | 作用 |
| --- | --- |
| `⌘/Ctrl + Enter` | 生成 |
| `Esc` | 关闭放大视图 / 取消生成 |

## 结构

```
docs/               ← GitHub Pages 根目录
  index.html
  styles.css
  .nojekyll         ← 避免 Jekyll 处理下划线开头的路径
  js/
    app.js          主控：状态机、校验、历史、灯箱
    api.js          传输层：双模式、模型表、失败图识别
    highlight.js    NAI 权重语法高亮
    vault.js        Key 加密保管库
    store.js        会话内历史 + 偏好
server.mjs          可选的本地服务（静态托管 + 代理）
```

## 权重语法高亮

输入框会实时给带权重的片段上色（黑底：偏红=加权，偏蓝=降权，越亮幅度越大）：

| 语法 | 权重 |
| --- | --- |
| `5::text::` | 5 |
| `-5::text::` | −5 |
| `{text}` | ×1.05，可嵌套 |
| `[text]` | ÷1.05，可嵌套 |

`()` 不视为权重语法——真实 tag 本身就含括号（如 `sho_(sho_lwlw)`）。
